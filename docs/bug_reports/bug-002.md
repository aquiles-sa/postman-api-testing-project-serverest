# BUG-002 - Status Code retornado incorretamente

| Item       | Informação                                                                |
| ---------- | ------------------------------------------------------------------------- |
| ID         | BUG-002                                                                   |
| Título     | Busca de um usuário inexistente retorna Status Code `400` em vez de `404` |
| Status     | Aberto                                                                    |
| Severidade | Baixa                                                                     |
| Prioridade | Baixa                                                                     |
| Tipo       | Funcional                                                                 |
| Módulo     | Consulta de Produtos                                                      |
| Ambiente   | https://serverest.dev/produtos                                            |
| Data       | 24/08/2026                                                                |
| Autor      | Aquiles Araujo                                                            |

---

## Descrição

Ao informar um identificador `_id` de um usuário não existente como parâmetro do caminho `https://serverest.dev/produtos` , a API retorna o Status Code `400`.

---

## Pré-condições

- A API deve estar disponível;

- O identificador utilizado na requisição não deve pertencer a nenhum usuário registrado.

---

## Passos para a reprodução

- Acessar a API ServeRest;

- Enviar uma requisição HTTP `GET` para o endpoint `produtos/{_id}`;

- Informar um identificador `_id` inexistente no parâmetro do caminho do endpoint;

- Executar a requisição.

---

## Resultado esperado

- A requisição deve retornar uma mensagem informando que nenhum produto foi encontrado;

- O Status Code de retorno deve ser `404`, visto que o elemento requisitado não foi encontrado.

---

## Resultado atual

- A requisição retorna uma mensagem informando que nenhum produto com o identificador `_id` foi encontrado;

- O Status Code de retorno é `400`.
